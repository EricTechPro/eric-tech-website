# Project Codex Memory

This folder stores project-level agent memory for the Eric Tech website.

- `memory/project.md` is shared, portable context that can be committed.
- `settings.local.json` is private local context for this machine and should stay gitignored.
- `settings.local.example.json` documents the local settings shape without personal values.

Before making changes in this project, agents should read `AGENTS.md` and `memory/project.md`.
